# Utsav Copilot

> A living event plan for Indian family celebrations.

🚧 **Under construction** — see [docs/00_WALKTHROUGH.md](docs/00_WALKTHROUGH.md) for the full design.

## Getting Started

```bash
npm install
cp .env.example .env.local   # Add your Gemini API key
npm run dev                   # Start development server
npm test                      # Run tests
npm run typecheck             # TypeScript check
npm run lint                  # ESLint
```
